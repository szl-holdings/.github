The check

When a required check cannot run, the result is not verified. An absent check never counts as passed.

Limits

What the checks mean.

The example demonstrates integrity and reproducibility against a retained reference. It does not establish whether a scientific conclusion is correct.

Unsigned, with an explicit reference

This example's receipt is unsigned. It does not verify trusted authorship or prevent replacement of all files and hashes together. A changed file is detected only while the retained reference remains unchanged.

Donor labels preserve source grouping. They do not independently authenticate donor identity.

No biological or clinical claim

The example runs no gene-signature scoring, reports no biological findings, and claims no superiority over AUCell, UCell, or Seurat. It makes no clinical-use claim.

Per-donor summaries are descriptive. There is no hypothesis test treating cells as independent biological replicates. The language-model records are a separate evaluation.
