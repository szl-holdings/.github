Promotion contract

A card is an index. Not a verdict.

Promotion requires exact lineage, clear boundaries, reproducible evaluation, and explicit restart and throughput evidence.

Weights

Base model and license lineage, weight/adapter hashes, clean load receipts, held-out and stress tests, restart and reproduction evidence, latency, memory, and energy context.

Datasets

Schema, lineage, privacy posture, consent assumptions, splits, validation status, and update policy.

Kernels

Canonical source, hardware matrix, executable tests, benchmark protocol, and non-model classification contract.

Spaces

Dependency pins, deployment revision, privacy behavior, and reproducible local path for exact served commit.

Language for claims

Signal maturity by evidence, not marketing.

We use explicit classes and avoid mixing integrity checks with model quality or commercial readiness.

Evidence classes

Classes used in the public portfolio include: PROVED, MEASURED, MODELED, REPORTED, CONJECTURE, and ROADMAP.
