## One governed loop

```text
signal → reason → policy → bounded action → receipt → independent verification
                     ↑                                      │
                     └──────────── verified feedback ───────┘
```

The model proposes. A separately named policy gate validates authority and
evidence. The runtime executes only inside a declared bound. A portable receipt
records the path for independent review.

## Evidence before adjectives

Claims use **PROVED**, **MEASURED**, **REPORTED**, **MODELED**,
**CONJECTURE**, or **ROADMAP**. Runtime state is a separate axis:
**OPERATIONAL**, **PARTIAL**, **DEGRADED**, **UNAVAILABLE**, or
**HISTORICAL**.

At canonical Lean revision
[`675d62b`](https://github.com/szl-holdings/lutar-lean/blob/675d62bd6f035047283fd3798440edad049635c2/README.md#tier-1--locked-proven-sorry-free-count-machine-enforced),
the corpus machine-enforces exactly eight locked-proven formulas. Lambda
uniqueness remains **Conjecture 1**, not a theorem.

A live route proves reachability at an observed time. A signed receipt proves
integrity and origin within its stated scope. Neither automatically proves
accuracy, safety, performance, compliance, or authorization to deploy.
