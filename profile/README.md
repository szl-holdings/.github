## Security record

Receipt verification survived an independent multi-model adversarial review
(39 executable PoCs; crypto core held; 37 semantic findings fixed and
regression-locked in CI). Missing evidence yields INCOMPLETE, never PASS.

*IAM says what an identity may access. a11oy proves what an AI agent was
authorized to do, what it actually did, and whether the required evidence exists.*
