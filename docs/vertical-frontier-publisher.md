# Vertical Frontier publisher

The central publisher owns one exact mapping:

`szl-holdings/vertical-services/frontier` → `SZLHOLDINGS/vertical-frontier`

It accepts only the current protected source tip, materializes an explicit file closure, builds the non-root image, binds the source revision, restarts the target, compares every published byte, and probes the declared public routes.

The public inference default is `ROUTE_ONLY`. Models may propose and embedded kernel references may check, but neither may authorize consequential action. Human binding remains required and public effectors remain disabled.

Publication evidence is retained as an immutable workflow artifact. A running Space or HTTP 200 proves reachability only; it does not establish production authorization, benchmark superiority, adoption, funding, revenue, or an investment outcome.
